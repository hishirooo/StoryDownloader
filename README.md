# 📚 StoryDownloader

**StoryDownloader** là một công cụ đơn giản giúp tải truyện từ trang [truyenfull.vision](https://truyenfull.vision) và xuất ra định dạng EPUB để đọc offline.

## 🚀 Tính năng

- Tải truyện từ trang web truyenfull.vision
- Tự động chuyển đổi nội dung sang định dạng EPUB
- Dễ sử dụng, chỉ cần chạy một file Python duy nhất

## 🛠️ Cài đặt

```bash
git clone https://github.com/hishirooo/StoryDownloader.git
cd StoryDownloader
pip install -r requirements.txt
```

## 📦 Sử dụng

Chạy script chính:

```bash
python main.py
```

Hoặc sử dụng `truyenfull_vision.py` nếu bạn muốn tùy chỉnh thêm.

## 📁 Cấu trúc thư mục

StoryDownloader/
